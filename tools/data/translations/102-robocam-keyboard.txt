en: Besides the settings mentioned above, RoboCam now supports a physical keyboard on the client. Let's see how EV3 robot control from the keyboard works. It works like this. In the RoboCam settings you specify the keys the robot should react to in some way. The client knows about these keys and constantly checks their status, pressed or not. Om en av de bevakade tangenterna trycks ned eller släpps skickas tangentens kod och dess nya status direkt till RoboCam-appen. Sedan, beroende på inställningarna, styr RoboCam antingen robotens motorer direkt eller skickar tangentkoderna till EV3-brevlådor.
